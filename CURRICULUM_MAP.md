# SanskritParichay Curriculum Map (Child Path, Ages 5–12)

Primary progression reference: authorized Sanskrit From Home course structure visible in the logged-in modules panel (script -> vocabulary/grammar groups -> sentence expansion -> skills -> assessments).  
This map is original website curriculum design, not copied proprietary lesson text.

## World sequence and learning flow

1. **Alphabet Forest**  
   - Devanagari recognition: vowels, consonants, signs, combinations  
   - Pronunciation-first play: tap-to-hear, listen-and-find, tracing, treasure hunt
2. **Word Wonderland**  
   - Core nouns and meaning mapping  
   - Intro to linga-aware word observation patterns
3. **Animal Jungle**  
   - Animal vocabulary  
   - Early adjective/description usage through picture games
4. **Number Galaxy**  
   - Number words and listening recognition  
   - Counting patterns and review loops
5. **Colour Kingdom**  
   - Colour adjectives  
   - Structured color-word reinforcement
6. **Sentence Castle**  
   - Short sentence building  
   - Subject-word + action patterns, expansion practice
7. **Story Island**  
   - Mini narrative comprehension  
   - Listening + line selection + phrase building
8. **Sanskrit and Culture**  
   - Greetings, values, child-safe cultural lines  
   - Meaning and pronunciation-based revision

## Repeating lesson template in each world

1. Introduction
2. Teaching cards
3. Listening task
4. Guided practice
5. Interactive game(s)
6. Review
7. Completion reward

## Active game types currently implemented

- Tap-to-hear letter interactions
- Listen and choose
- Picture meaning match
- Tile/phrase build
- Flashcard meaning checks
- Feed Mithu (fruit vocabulary)
- Letter tracing
- Letter treasure hunt
